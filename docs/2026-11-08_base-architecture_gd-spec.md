# F1: Базовая архитектура проекта — GD Spec

**Дата:** 2026-11-08
**Фича (feature-index):** F1
**Статус:** Черновик (интервью в процессе)

## 1. Цель
Создать масштабируемую основу проекта: структура интерактивной визуальной новеллы и графического комикса в Unity 6.6, система сцен и компонентов для дальнейшей разработки. Объединить VN и комикс общей сюжетной логикой при независимых подсистемах отображения; предусмотреть будущую AR-интеграцию.

## 2. Базовая единица контента
Отдельная интерактивная сцена или панель комикса. Каждая сцена может содержать: фон, персонажей, диалоги, иллюстрации, анимации, аудио, интерактивные элементы. Сцены объединяются в эпизоды и главы. Между сценами — нелинейные переходы, зависящие от выборов пользователя и состояния сюжета.

## 3. Хранение данных сюжета
- Сценарий/диалоги/развилки/условия/переменные: Ink.
- Визуальные ресурсы, настройки сцен, персонажей, звук, анимации: средства Unity, ScriptableObjects там, где целесообразно.
- Сюжетная логика отделена от визуального представления.
- Окончательная структура хранения: TBD (согласовать перед реализацией).

## 4. Разделение режимов
- VN и комикс — две независимые подсистемы отображения.
- Общие: сюжетная логика, персонажи, переменные, сохранения.
- VN: диалоги, персонажи, выборы.
- Комикс: последовательность иллюстрированных панелей, вертикальная прокрутка, анимация, скроллителлинг.
- Переключение форматов не обнуляет прогресс.

## 5. Сохранения
- JSON-файл в persistentDataPath.
- Сохранять: текущую главу, сцену, принятые решения, сюжетные переменные, данные состояния.
- Структура с возможностью расширения и версионирования.

## 6. Обоснование (почему сейчас)
Архитектура нужна, чтобы: создать масштабируемую основу для нелинейного интерактивного повествования; обеспечить логичную взаимосвязь выборов и последствий; объединить VN с интерактивным комиксом; предусмотреть будущую AR-интеграцию; обеспечить удобное добавление новых глав, персонажей, мифологических существ, сцен и механик без постоянной переработки кода.
