# Decision Log

## 2026-11-08
- Созданы docs/project-concept.md и docs/feature-index.md по концепции пользователя.
- Git не установлен в окружении — ветки для фич не создаются; работа ведётся в текущей папке.
- Распределение: некоммерческий учебный проект, F2P-темы не применяются.
- Фичи сессии: F1 (архитектура), F2 (повествование), F3 (комикс/скроллителлинг).
- Формат интервью: 5 вопросов/раунд, раунды до остановки пользователем, варианты А–Е.
- F1 Раунд 1 зафиксирован: единица контента = сцена/панель; Ink для сюжета + Unity/ScriptableObjects для визуала; VN и комикс — независимые подсистемы отображения, общая логика/данные/сохранения; сохранения JSON в persistentDataPath с версионированием; обоснование архитектуры зафиксировано.
- F1 Раунд 2 зафиксирован: Ink-интеграция — официальный ink-Unity-integration + C#-обёртка; загрузка — Addressables для тяжёлых ассетов + SceneManager для экранов; версионирование сохранений — schema_version + миграции; AR — абстрактный интерфейс «источник контента»; риск рассинхронизации — единый контроллер состояния, общие переменные, без дублирования сюжетной логики.
- F1 Раунд 3 зафиксирован: источник истины сюжета — Ink-файл; ScriptableObjects — метаданные; пайплайн сценарист→разработчик; тестирование комбинированное (авто Ink + ручное прохождение); оптимизация памяти комикса — lazy load + prefetch + пул; единый контроллер состояния критичен против рассинхронизации.
- F2 Раунд 1 зафиксирован: полноценная система диалогов/выборов/условий/последствий/отношений; числовые affinity (включая мифологические существа); последствия комбинированные (немедленные + отложенные); переменные: флаги + числа + инвентарь сюжетных предметов; MVP — небольшой завершённый эпизод.
- F2 Раунд 2 зафиксирован: UI диалогов зависит от режима (VN классический + кинематографичная подача/CG; комикс — текст в панелях + вертикальная прокрутка); анимации реакций — смена эмоций/поз + моргание/дыхание, без скелетной анимации в MVP; инвентарь — иконка HUD + всплывающий список; MVP-эпизод 3–5 выборов, 2–3 концовки; причинно-следственные связи критичны (очевидные и скрытые последствия).
- F3 Раунд 1 зафиксирован: прокрутка — гибрид свободной + мягкий snap; появление элементов — fade + slide + параллакс + триггеры; параллакс только в ключевых сценах; темп — гибрид (пользователь скроллит, система вставляет паузы/эффекты); MVP — небольшой демо-фрагмент с несколькими панелями, базовыми анимациями, одним параллаксом и одним интерактивным элементом.
