# F2: Система интерактивного повествования — GD Spec

**Дата:** 2026-11-08
**Фича (feature-index):** F2
**Статус:** Черновик (интервью в процессе)

## 1. Цель
Создать механику диалогов, сюжетных выборов, переходов между сценами и последствий решений пользователя. Поддержка нелинейного повествования с причинно-следственными связями.

## 2. Объём MVP
Небольшой завершённый сюжетный эпизод с ограниченным количеством развилок, демонстрирующий основные возможности системы. Не реализовывать сразу все сюжетные ветки.

## 3. Диалоги и выборы
Полноценная система: ветвления + условия + последствия + отношения с персонажами. Выборы влияют на ближайшие реплики, дальнейшее развитие истории, раскрытие персонажей, доступность сцен и варианты финала.

## 4. Отношения с персонажами (affinity)
Числовые показатели отношений (доверие, симпатия, расположение, настороженность, страх, уважение, враждебность). Влияют на доступность диалогов, дополнительных эпизодов, реакций и ветвей. Применимо и к мифологическим существам. Не только романтическая система.

## 5. Последствия
Комбинированно: немедленные (изменение диалога/реакции/визуала/ближайшего события) + отложенные (через переменные, влияние спустя сцены/эпизоды/главы). Причинно-следственные связи, логично вытекающие из действий.

## 6. Переменные
Три типа:
- Булевы флаги (действия, тайны, условия, решения).
- Числовые переменные (отношения, сюжетно значимые показатели).
- Инвентарь сюжетных предметов (артефакты, обереги, ключи, письма).

Связаны с единой системой сюжетного состояния и сохранений. Для MVP — только необходимые.

## 7. Обоснование
Нелинейность повышает эмоциональное вовлечение, чувство личного участия, реиграбельность; позволяет по-разному раскрывать мифологию и тайны; делает выборы значимыми; реализует причинно-следственные связи проекта.

- **Раунд 2 (2026-11-08):**
  - UI диалогов: зависит от режима. VN — полноэкранный фон, спрайты персонажей, текстовый бокс внизу, имя говорящего, выборы; кинематографичная подача (скрытие UI, акцент на иллюстрациях, смена планов, CG). Комикс — реплики/текст интегрируются в иллюстрированные панели, переходы через вертикальную прокрутку. Оба режима используют единые данные Ink.
  - Анимации реакций: минимальные — смена эмоций/поз + циклические (моргание, дыхание). Поддержка анимированных и статичных спрайтов. Без скелетной анимации в MVP.
  - Инвентарь: иконка в HUD + всплывающий список; предметы с названием/изображением/описанием/сюжетным ID; влияние на доступность действий/выборов в Ink; компактный, без RPG-характеристик; не нарушать прокрутку в комиксе.
  - Объём MVP-эпизода: 3–5 выборов, 2–3 концовки; минимум одна проверка отношений; немедленные и отложенные последствия; условная доступность реплик; эмоциональные реакции; хотя бы один сюжетный предмет (если обоснован).
  - Причинно-следственные связи критичны: без них выборы декоративны, теряется влияние на мир, реиграбельность, эмоциональное вовлечение; в проекте раскрывают фольклор (запреты, обещания, обряды, взаимодействие с существами); поддержка очевидных и скрытых последствий.
