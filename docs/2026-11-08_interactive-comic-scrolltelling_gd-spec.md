# F3: Интерактивный комикс и скроллителлинг — GD Spec

**Дата:** 2026-11-08
**Фича (feature-index):** F3
**Статус:** Черновик (интервью в процессе)

## 1. Цель
Проработать механику вертикальной прокрутки иллюстрированных сцен, появления элементов, анимации, параллакса и управления темпом повествования.

## 2. Механика прокрутки
Гибрид: свободная вертикальная прокрутка + мягкий snap к сюжетно важным композициям. Пользователь сохраняет контроль; snap без резких скачков; возможность возврата к предыдущим панелям; поддержка touch (мобильные) и мышь (ПК); панели разной высоты, включая полноэкранные; ощущение непрерывного художественного полотна.

## 3. Появление элементов
Комбинация: fade-in + slide-in + параллакс + анимации по триггерам прокрутки. Повторное воспроизведение/корректное восстановление при обратной прокрутке. Режим Reduced Motion для пользователей с чувствительностью к анимациям.

## 4. Параллакс
Многослойный параллакс выборочно — только в ключевых сценах (мистический лес, появление существа, переходы реальное/потустороннее, кинематографичные моменты). Обычные диалоговые/статичные панели — без сложного параллакса. Настраиваемое количество слоёв/скорости на сцену. Учёт производительности мобильных устройств.

## 5. Темп повествования
Гибрид: пользователь скроллит, система вставляет паузы/эффекты (появление персонажей/объектов, освещение, звук, задержки раскрытия, анимации по позиции скролла, интерактивные выборы). Временные задержки без долгой блокировки управления. Не создавать ощущение потери контроля; поддерживать повторный просмотр.

## 6. Обоснование
Скроллителлинг превращает пассивное чтение в интерактивное переживание; управляет вниманием и эмоциональным напряжением; делает переходы частью драматургии; отличает проект от статичного комикса. Дополняет нелинейное повествование, не заменяет выборы.

## 7. Объём MVP
Небольшой демонстрационный фрагмент вертикального интерактивного комикса: несколько последовательных иллюстрированных панелей, плавная прокрутка, базовые анимации появления, один пример параллакса, хотя бы один интерактивный сюжетный элемент. Все механики расширяемы без переписывания системы.
